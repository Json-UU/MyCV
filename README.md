# Jason Pretorius

A responsive personal CV built with HTML and CSS for M07T01 Practical Task 2.

## Preview

Open `index.html`, or run `python -m http.server 8080` in the repository directory.

## Deployment

GitHub Pages publishes the `main` branch from `/` (root). No build dependencies or backend are required.

The page includes professional experience, skills, education and certifications, selected projects, and professional contact links.
